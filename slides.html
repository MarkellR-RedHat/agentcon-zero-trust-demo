01 The problem

We are handing agents real tools and hoping they behave.

An agent with file, web and shell access is an insider with no judgment and no audit trail. "Add a guardrail" sounds like the answer. It is half of one: a filter that blocks dangerous-looking content cannot tell your incident responder from the attacker, and it still misses attacks that do not look dangerous.

This talk builds the other half: progressive access, a policy scoped to the task, and a trace of every tool call.

03 Two lanes, same agent

Every tool call goes through a policy, or it does not.

No gate

  • The model calls a tool, the tool runs.
  • Reads /home/deploy/.ssh/id_rsa when asked.
  • POSTs .env to an outside URL.
  • Runs the reverse-shell "diagnostic".

Scoped policy

  • Each call checked against the task's scope.
  • Secret paths denied, by rule not by content.
  • Egress only to the allowed host.
  • Only the task's own command runs.

The sandbox holds only fake data and cannot reach the network, so a "successful" attack lands in a sink and nowhere real. Every call is traced to MLflow.

05 The guardrails paradox

Guardrails you don't control can lock the defender out. Scope the ones you do.

July 2026: an autonomous AI agent moved through Hugging Face's dataset pipeline over a weekend, chaining 17,000+ actions across short-lived sandboxes. When the team started the log analysis, they first used frontier models behind commercial APIs. It did not work: the requests were blocked by the providers' safety guardrails, which cannot tell an incident responder from an attacker. They ran the forensics on an open-weight model on their own infrastructure and did in hours what would have taken days.

What a content filter costs

The blunt filter guesses from the bytes. It let through the attacks that read like ordinary ops work and blocked the honest status-page check. The scoped policy, keyed on the task, let 0 through and blocked no honest work.

06 Takeaway

Zero trust for agents is scope plus a trace, not a bigger refusal list.

  • Grant capability progressively, and red team each grant before the next.
  • Scope the policy to the task, so it tells a responder from an attacker.
  • Trace every tool call, because you cannot govern what you cannot see.
